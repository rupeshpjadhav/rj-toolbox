Free online developer and QA tools

Ten everyday utilities for developers, testers and anyone who works with data. Everything runs in your browser, so your data stays on your device.

All tools

  • Test Data GeneratorCreate realistic fake records for testing, demos and database seeding, then export them as JSON, CSV, XML, HTML, SQL inserts, Python or JavaScript.
  • Random Password and Key GeneratorGenerate strong random passwords and keys with your choice of length and character sets, using your browser’s cryptographically secure random number generator.
  • CSV, TSV, JSON and XML ConverterConvert data between CSV, TSV, JSON, XML and a single column of values in any direction, with automatic format detection and file upload.
  • JavaScript Minifier and ValidatorCompress JavaScript with Terser for a smaller file, or validate code and see syntax errors with their line numbers.
  • JSON Formatter and ValidatorBeautify and validate JSON, find the exact line of an error, and convert JavaScript object literals into strict JSON.
  • SQL Formatter and BeautifierMake SQL queries readable or minify them to one line, for Standard SQL, MySQL, PostgreSQL and Transact-SQL.
  • Diff Checker: Compare Two TextsCompare two blocks of text or two files and see what changed, line by line.
  • Case ConverterChange text to UPPERCASE, lowercase or Title Case in one click.
  • camelCase, PascalCase, snake_case and kebab-case ConverterTurn any phrase into programming naming styles as you type: camelCase, PascalCase, snake_case, kebab-case and Capitalized Case.
  • YAML ValidatorCheck YAML files for syntax errors before they break a deployment, from Kubernetes manifests to GitHub Actions workflows.

The tools process your text and files in your browser; nothing you paste is uploaded or stored. Read the tool guides for tips on each one.
